# Security policy

This repository does not yet publish supported packages. Until a private
security contact is selected, report suspected vulnerabilities privately to
the future project owner rather than opening an issue containing exploit or
credential details.

Never commit COPR credentials, forge tokens, signing material, or secrets.
If a secret is exposed, revoke it immediately; deleting it from the latest Git
revision is not sufficient.

Packaging-only defects that do not expose users to a security risk can use the
normal issue tracker once its URL is selected.
